# FENB 0.5a

Panel updates, expanded reflections and nine built-in profiles for FENB, a graphics mod for Flyff inspired by ENBSeries. This release includes all changes since 0.4a.

## Panel updates and recovery

- The first panel opening in a game session checks for a newer version. **FENB updates** in the **…** menu also provides update and rollback controls, with English and Russian status messages.
- Downloads use a versioned release ZIP and a matching `FENB-update.json` manifest. The worker checks archive size, SHA-256, the four allowed payload entries and the x86 DLL format before staging an update.
- Installation waits for the game process to exit, preserves `FENB.ini` and `FENB-presets/`, and keeps one verified previous DLL and license-notice snapshot for rollback. Installation errors trigger restoration; interrupted transactions can be recovered.
- The worker is embedded in the DLL and runs through Windows PowerShell outside the rendering thread. Internet access and write access to the game folder are required; no separate updater executable is installed.

**Users on 0.4a or earlier must install 0.5a manually once.** Those releases do not contain the panel updater. Subsequent compatible releases can be installed from the panel when their ZIP and manifest are published together.

## Graphics changes

- **Water reflections:** separate Sky Only, SSR Performance and SSR Quality modes; reflection resolution, ray samples, refinement, trace distance, bias, thickness, confidence and soft-fallback controls. Reflected surfaces are retained more consistently. Planar and Hybrid modes remain unavailable.
- **Surface reflections:** optional material-aware polished paving and stone with screen-space object reflections, captured sky fallback, directional highlights and roughness, strength and distance controls. Recognition includes captured Flaris plaza and yellow road materials while excluding grass regions. Batched terrain masks reduce repeated state capture; blended terrain depth, coverage and stone response have been refined. The feature remains off by default.
- **Local lighting:** light sources rebase after teleports; additional known windows, machinery, signs and lamps supply emission. Static emitters survive short visibility gaps.
- **Particles and auras:** a dedicated control enhances recognized equipment-refinement, pet-bead and elemental-weapon glows; aura enhancement is retained in crowded scenes. Native geometry, animation and blending remain in use.
- **Sky:** bright sun cores are restored without amplifying lens ghosts.
- **Diagnostics:** opt-in captures retain more material evidence in crowded scenes. The published DLL is a normal build without diagnostics enabled.

## Profiles, panel and documentation

- Added **Default (Blue Water)** and **Default (Cyan Water)**, bringing the embedded profile count to nine. Both retain the default image settings while changing water appearance.
- Default, Low-end PC and Potato appear first in the selector. Lightweight profiles preserve the default tone; Potato now keeps brightness adaptation and tone balance while disabling costly geometry effects and WaterFX.
- Particle processing and Detailed effect quality remain off by default. Existing saved settings are preserved.
- Color correction and Bloom start collapsed whenever the panel opens.
- The README includes cropped in-game examples of local lighting, reflection modes, water appearances, color and weather, alongside the existing comparison pairs.

## Install or update

Download **FENB-0.5a-win32.zip**, close the game and copy `d3d9.dll` beside `Neuz.exe`. Keep `LICENSES.txt` with the installed files. New installations also need the supplied `FENB.ini`; updates should retain the existing configuration and `FENB-presets/`. `INSTALL.txt` contains English and Russian instructions. Open the panel with **Shift + Enter**.

The release also provides **FENB-update.json** for the panel updater and a **.sha256** checksum for manual verification. These are release assets, not additional files to copy into the game folder.

Requires Windows and a compatible **32-bit DirectX 9 Flyff client**. FENB targets **Homesickness Flyff**; other clients remain unverified. Depth-based effects require a supported NVIDIA driver depth-copy path. Screen-space reflections cannot reconstruct off-screen or hidden geometry, and performance depends on the scene, GPU and settings. See the [README](../../README.md) and [rendering notes](../RENDERING.md) for limitations and recovery instructions.
