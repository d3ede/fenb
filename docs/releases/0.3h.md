# FENB 0.3h

The first packaged GitHub release of FENB, a graphics mod for Flyff inspired by ENBSeries.

## Included

- Adjustable color, bloom, SSAO, sun rays, fog, depth of field, brightness adaptation and local lighting.
- Reconstructed sky and cloud textures, fine night stars and enhanced recognized world particles.
- WaterFX with animated wave shading, refraction, screen-space and sky reflections, depth-based absorption, optional caustics and independent refractive footsteps. This build improves reflection hits at distant banks and rejects foliage streaks and mixed-depth color samples.
- FXAA, SMAA and hardware MSAA where supported.
- A compact English/Russian panel with five translated built-in profiles, custom profiles, automatic saving and an optional compact cursor.
- Local time and weather overrides and an FPS unlock on supported Homesickness clients. The time override remains active when image effects are disabled.
- Updated README with three in-game comparison pairs, installation instructions and hotkeys, plus the approved violet branding.

## Install or update

Download **FENB-0.3h-win32.zip**. Close the game, extract the archive and copy `d3d9.dll` and `FENB.ini` beside `Neuz.exe`; keep `LICENSES.txt` with them. Read `INSTALL.txt` for English and Russian instructions. If another `d3d9.dll` is already installed, back it up before replacing it; chaining graphics proxies is unsupported.

When updating FENB, replace the DLL and keep your existing `FENB.ini` and `FENB-presets/` to preserve settings and profiles. Built-in profiles are embedded in the DLL.

Press **Shift + Enter** to open the panel, **Right Shift + F12** to toggle image effects and **Ctrl + S** to save while the panel is open. Settings also save automatically.

## Compatibility and limitations

- Requires Windows and a compatible **32-bit DirectX 9 Flyff client**. FENB currently targets **Homesickness Flyff**; other clients are unverified.
- Depth-based effects require a supported **NVIDIA driver depth-copy path**. Unsupported effects fall back or remain inactive.
- Screen-space reflections use visible geometry rendered before water; off-screen objects and later transparent geometry cannot be reconstructed. Some precision and disocclusion artifacts remain possible.
- Native FPS and environment overrides require a recognized client layout. Driver and VSync limits still apply; a higher render rate does not imply interpolated simulation.
- The release DLL is a normal build with diagnostics disabled. Live appearance and performance vary with the client, scene and GPU; automated fixtures do not establish compatibility with every map or system.
