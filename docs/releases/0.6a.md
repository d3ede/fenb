# FENB 0.6a

Smoother native FPS unlock and more stable surface reflections for FENB, a graphics mod for Flyff inspired by ENBSeries. This release includes all changes since 0.5d.

## Native FPS unlock

- Movement, animation, held input and camera updates can now advance on every render frame in the supported Homesickness client, using elapsed time. Combat counters, hit-stop duration and effect lifetimes keep their native timing.
- The full native adapters discover compatible relocated functions and global data after client updates. Required instruction probes, native class/vtable ownership and call relationships are checked together before installation; incompatible layouts are rejected.
- Player and remote-mover positions, rotation and world matrices are updated together. Supported skill and equipment attachments refresh after mover and bone updates, keeping their origins in the same coordinate space.
- Removed render-only actor-position extrapolation, which could separate models from shadows, targeting and skill origins. The conservative fallback retains native positions when the full adapter is unavailable; in that fallback, positions still update at the native 16 ms cadence.
- Disabling Unlock FPS restores the native limiter and installed patches. Driver and VSync limits still apply.

## Surface reflections and lighting

- Stabilized horizontal reflection receivers across layered and translucent terrain draws.
- Receiver heights use camera-relative coordinates and a full-precision mask, with a transform-roundoff allowance for large map coordinates. This addresses moving triangular overlays and missing reflection bands when rotating or raising the camera.
- Depth validation accounts for native D16/D24 precision and MSAA coverage. Validated horizontal receivers also supply their geometric plane to local lighting, reducing depth-quantization bands on paving.

Screen-space reflections still depend on visible scene geometry. Depth-based effects require a supported NVIDIA driver depth-copy path; other clients and arbitrary compiler/layout changes remain unverified. These fixes do not remove every possible source of aliasing or change native draw distance.

## Validation

Native tests cover combined player/mob movement, animation events, matching attachment origins and world matrices, input/camera updates and legacy timing at 30–1000 render FPS. Both inspected client builds passed installation/rollback checks; injected ABI mismatches were rejected without partial image changes. The full rendering, HUD, settings, runtime, UI and updater suites passed, together with x86 export/dependency checks. A live Homesickness run confirmed full native-hybrid activation, and the reported scene showed no visible artifacts after updating. This is not a guarantee for every map, skill or hardware configuration.

The published DLL has diagnostics disabled. Bounded multi-frame reflection captures remain available in developer diagnostics builds.

## Install or update

**From 0.5a or later:** use **FENB updates** in the panel's **…** menu. Download the update, close the game when prompted, wait for completion and launch normally. Settings, language and custom profiles are preserved; the previous DLL remains available for rollback.

**Manual installation:** download **FENB-0.6a-win32.zip**, close the game and copy `d3d9.dll` beside `Neuz.exe`. Replace `LICENSES.txt` with the supplied copy. New installations also need the included `FENB.ini`; updates should keep the existing configuration and `FENB-presets/`. Users on 0.4a or earlier need this manual replacement once. `INSTALL.txt` contains English and Russian instructions. Open the panel with **Shift + Enter**.

The release includes **FENB-update.json** for automatic updates and a **.sha256** checksum for manual verification. The updater requires Windows PowerShell, Internet access and write access to the game folder.
