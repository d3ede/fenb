# FENB 0.4a

Lighter starting settings and two performance profiles for FENB, a graphics mod for Flyff inspired by ENBSeries.

- **Particle processing** and **Detailed effect quality** are now off in the shipped configuration and built-in profiles. Both can still be enabled individually.
- **Default (Low-end PC)** keeps the default look and WaterFX while disabling SSAO.
- **Default (Potato)** retains the default color correction and sky settings, keeps bloom at quarter dimensions and replaces SMAA with FXAA. It disables SSAO, sun rays, fog, depth of field, brightness adaptation, lighting balance, local lighting, WaterFX and refractive water footsteps. Water uses the native game material.
- All seven built-in profiles are embedded in the DLL, with English and Russian names. Existing custom profiles, language, time/weather overrides, hardware MSAA and FPS controls are preserved when changing profiles.

These profiles reduce optional rendering work; FPS gains depend on the client, scene, GPU and hardware antialiasing settings. Potato preserves the main color treatment, bloom and sky, but water, atmospheric effects and dynamic lighting differ from Default.

## Install or update

Download **FENB-0.4a-win32.zip** and close the game before replacing `d3d9.dll` beside `Neuz.exe`. Keep `LICENSES.txt` with the installed files. `INSTALL.txt` contains English and Russian instructions.

For a new installation, copy the included `FENB.ini` as well. When updating, keep your existing `FENB.ini` and `FENB-presets/` to preserve your settings. Existing configurations retain their saved effect switches: select a built-in profile to use the new defaults, or switch Particle processing and Detailed effect quality off manually.

Press **Shift + Enter** to open the panel and choose a profile. **Right Shift + F12** toggles image effects.

Requires Windows and a compatible **32-bit DirectX 9 Flyff client**. FENB targets **Homesickness Flyff**; other clients remain unverified. Depth-based effects still require a supported NVIDIA driver depth-copy path. See the [README](../../README.md) and [rendering notes](../RENDERING.md) for installation, comparisons and limitations.
