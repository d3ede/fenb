# FENB 0.5d

Four interface languages, refreshed profiles and a clearer settings panel for FENB, a graphics mod for Flyff inspired by ENBSeries. This release includes all changes since 0.5a.

## Interface and languages

- Added complete **Spanish** and **Brazilian Portuguese** translations alongside English and Russian, including profile names, tooltips and update/restart/rollback messages. A language dropdown replaces the two-language selector; English remains first and the default. Language settings survive profile changes and effect resets.
- The panel now loads **Tahoma** from Windows, with regular text and emphasized headings. The licensed embedded Inter font remains the fallback; Tahoma is not redistributed.
- Navigation arrows, section actions, numeric inputs and reset controls use aligned columns. Profile spacing, inset parameter rows and the Effects caption have been refined for readability.

## Profiles

The nine built-in profiles are now **Default**, **High-end PC**, **Low-end PC**, **Potato**, **Blue Water**, **Cyan Water**, **Warm tones**, **Cool tones** and **Soft colors**. Their names are translated in all four interface languages.

- **High-end PC** retains Default's color treatment while enabling detailed effect quality, particle processing, material-aware paving/stone reflections, full-resolution SSR Quality with 48 ray steps and 12 refinements, and subtle caustics. Hardware MSAA remains a separate user choice.
- **Warm tones**, **Cool tones** and **Soft colors** adjust only color correction, preserving Default's water, bloom, scene effects and quality settings.
- The retained Default, Low-end PC, Potato and water variants keep their existing settings. Default and the regular profiles still leave Particle processing and Detailed effect quality off; High-end PC enables them.
- **Clear water**, **Golden light**, **Soft atmosphere** and **Night lights** have been removed from the built-in selector. Existing custom profile files and saved configuration values remain supported; updating does not automatically replace your current look.

## Surface reflections

- Material masks now account for the game's constant and slope-scale polygon depth bias while preserving native render state. This improves agreement with scene depth across camera angles and addresses horizontal reflection-acceptance bands.
- Receiver depth validation uses the physical depth interval of the surface over a pixel, including native MSAA coverage, while continuing to reject foreground occluders. Screen-space reflections still cannot reconstruct hidden or off-screen geometry; complete planar world reflections are not provided.

## Install or update

**From 0.5a:** use **FENB updates** in the panel's **…** menu. Download the update, close the game when prompted, wait for completion and launch normally. Settings, language and custom profiles are preserved; the previous DLL remains available for rollback.

**Manual installation:** download **FENB-0.5d-win32.zip**, close the game and copy `d3d9.dll` beside `Neuz.exe`. Replace `LICENSES.txt` with the supplied copy. New installations also need the included `FENB.ini`; updates should keep the existing configuration and `FENB-presets/`. Users on 0.4a or earlier need this manual replacement once. `INSTALL.txt` contains English and Russian instructions. Open the panel with **Shift + Enter**.

The release provides the matching **FENB-update.json** for automatic updates and a **.sha256** checksum for manual verification. The updater requires Windows PowerShell, Internet access and write access to the game folder.

Requires Windows and a compatible **32-bit DirectX 9 Flyff client**. FENB targets **Homesickness Flyff**; other clients remain unverified. Depth-based effects require a supported NVIDIA driver depth-copy path. The published DLL has diagnostics disabled. See the [README](../../README.md) and [rendering notes](../RENDERING.md) for screenshots, compatibility and recovery details.
