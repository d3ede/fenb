# Approved FENB logo kit

The approved **Refined Bloom** artwork: violet metal, an orbital ring and a star, with the corrected inner F contour.

This tracked directory preserves the complete approved kit for documentation and future integration. The original local export is kept at `artifacts/FENB-Approved-Logo-Kit/` in the project root. That export directory is ignored by Git.

## Contents

- `SVG/Dark/` and `PNG/Dark/`: bright violet artwork for dark backgrounds.
- `SVG/Light/` and `PNG/Light/`: deeper violet artwork for light backgrounds.
- `manifest.json`: all 12 compositions, their themes, transparency and dimensions.
- `00-FENB-all-variants.png`: a visual overview of the complete kit.

Each theme includes **stacked**, **symbol** and **horizontal** compositions, with both a themed background and a transparent background. There are **12 SVG files and 12 PNG files**.

| Composition | SVG dimensions | PNG dimensions |
| --- | --- | --- |
| Stacked | 1024 × 1024 | 2048 × 2048 |
| Symbol | 1024 × 1024 | 2048 × 2048 |
| Horizontal | 1600 × 500 | 3200 × 1000 |

## Usage

The root README selects the transparent horizontal PNG for the reader's light or dark theme. PNG preserves the approved bloom consistently; SVG filter rendering can vary between viewers.

SVG lettering is outlined and has no external font or raster dependencies. Transparent variants contain real alpha transparency, including the soft glow. The checkerboard in the overview is only a preview background.

Use these approved files when adding branding. Preserve their proportions, colors, contour and glow; keep the manifest and both formats together when updating the kit. Earlier branding experiments do not replace this approved artwork.
